# Kajol Sarkar Joy — CV Portfolio Website

This is a static, SEO-ready personal CV/portfolio website.

## Files
- `index.html` — main website
- `style.css` — responsive design
- `cv-preview.png` — CV preview from the supplied image
- `robots.txt` — search engine crawling rules
- `sitemap.xml` — sitemap for Google/Bing

## Before publishing
1. Replace `https://your-domain.com/` in `index.html` and `sitemap.xml` with your real domain.
2. Upload all files to your hosting provider.
3. If you have a custom domain, connect it to the hosting.
4. Add the site to Google Search Console and submit `/sitemap.xml`.
5. Keep the site public and make sure robots.txt is not blocking crawlers.

## Important
Google indexing is not instant and cannot be guaranteed. A public website, unique useful content, a proper sitemap, Search Console submission, and links from other websites can improve discoverability.
